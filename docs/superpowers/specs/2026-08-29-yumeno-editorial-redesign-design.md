# YUMENO 展示页重构设计

## 目标
将展示页从“交互式 AI 工作台”改为成熟产品官网：以真实角色图像、真实声音样本和清晰的产品结构为可信主体，减少技术营销话术与装饰性动效。

## 视觉方向
- 参考 AstrBot 的留白、主视觉聚焦和产品截图可信度。
- 参考《明日方舟》官网的章节节奏、深色信息带与品牌化排版。
- 参考 Canvas UI 的克制边框、静态图形和内容优先。
- 使用暖白、墨黑、雾蓝和少量朱红作为品牌色；不使用紫蓝渐变、ASCII 扫描或仿真的动态声波。

## 信息架构
1. 首屏：一句通俗定位 + Windows 下载入口 + 真实角色视觉。
2. 角色：角色设定、记忆和知识空间三项能力，使用编辑式三栏布局。
3. 声音：站内真实音频试听，展示“素材 → 人声片段 → 角色声音”的过程。
4. 架构：用静态线稿说明角色、知识、记忆、声音和行动如何协同。
5. 文档：在站内抽屉查看定位、声音工坊流程、运行方式和隐私说明。
6. 页尾：GitHub 源码、版本发布页和 Windows 下载入口。

## 交互边界
- 删除 PeelReveal、AsciiSweep 和合成 Web Audio 动效。
- 只保留真实音频播放、站内文档抽屉、导航锚点和按钮悬停反馈。
- 文档不跳转到 GitHub；GitHub 只作为源码和发布下载入口。
- 不展示内部评测数据。

## 真实素材
- 角色视觉：`D:/CodePython/YUMENO/data/live2d/Mortis/Mortis.png`。
- 声音片段：从 `data/voice_studio/sessions/acc8c91b4280/segments/segment_003.wav` 与 `data/tts/voices/6f48c821cb8d.wav` 复制，作为站内试听资源。
- 不复制模型权重、运行时和大型原始视频。

## 验收标准
- 首屏 5 秒内能理解“YUMENO 是什么、可做什么、从哪里下载”。
- 页面不出现上一版 ASCII、Peel 或合成声音效果。
- 声音模块能播放真实本地样本。
- 文档能在当前页面内打开并关闭。
- `npm run build` 通过；桌面和窄屏无横向溢出。
